# Invoice Calculator

A tool for calculating product costs and taxes.

## Features

- Unit price
- Quantity
- Tax calculation
- Invoice total

## How to Use

Enter product information and generate the invoice.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
